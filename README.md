# 阴阳 Yin-Yang

一个基于 Web 的阴阳（Yin-Yang）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5179/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 所有黑格必须上下左右连成一片
- 所有白格必须上下左右连成一片
- 任意 2×2 区域不能四格同色
- 题面给定的黑白格不能修改

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 黑 → 白 → 空 |
| 右键点格 | 直接填白 / 清除 |
| 按住拖动 | 连续涂色 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移
- **规则引擎**：2×2 三连、封闭区域、反证探测三类必然推理
- **自定义题板**：画出给定黑白格，载入后即可游玩或求解，保存到题库后可编辑或删除

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 图片识别导入

用 Playwright + Edge 识别题面图片里的网格与黑白圆点（黑圈 = 黑格、白圈 = 白格），生成题库格式后预览 / 写入。

```bash
# 只识别 + 预览（不写入）
npm run import-image -- 题面.png

# 只识别网格与圆点
npm run import-image -- 题面.png --dry

# 求解 + 唯一性检查（大网格可能超时，会给出警告）
npm run import-image -- 题面.png --verify

# 追加到题库（写入 src/game/imported-puzzles.ts，npm run gen 不会覆盖）
npm run import-image -- 题面.png --name "我的阴阳" --append
```

| 参数 | 说明 |
|------|------|
| `--name 名称` | 题库中显示的名称（默认「识图 · W×H」） |
| `--series 系列` | 系列名（默认「图片导入」） |
| `--difficulty 级别` | `easy` / `medium` / `hard` / `custom`（默认 `hard`） |
| `--size N` | 正方形网格边长；默认自动识别 |
| `--width N` / `--height N` | 非正方形题图的宽/高，可只给一边 |
| `--swap` | 交换黑/白圆点的含义（黑圈看作白格） |
| `--map 行,列=值` | 人工覆盖某格（行列从 1 开始，值 `0`/`1`/`2`），可重复或逗号分隔 |
| `--append` | 写入 `src/game/imported-puzzles.ts` |
| `--verify` | 求解并检查唯一解（超时会警告，不阻断导入） |
| `--dry` | 只识别网格与圆点，不求解、不写入 |
| `--max-nodes N` / `--timeout MS` | 唯一性搜索的节点 / 时间上限 |
| `--edge PATH` | 指定 Edge 路径（默认自动探测） |

识别流程：投影找贯穿整幅图的网格线 → 取最长等距线序列得到网格 → 每格中心暗度判断实心黑圈、圆环墨迹判断空心白圈 → 得到题面串。
网格外的坐标标签等文字不会被误认为圆点。40×40 这类大题的求解/唯一性检查容易超时，此时只用「预览 + `--append`」即可导入，参考解留空。

## 题板尺寸与形状支持

- **题面模型**：`width × height`（row-major），宽高各自独立，非正方形可以直接用。
- **内置题库**：6×6～12×12，均为正方形；内置参考解全部通过校验。
- **自定义题板**：宽 4–60、高 4–60，可输入任意非正方形组合（如 5×6、9×6、60×4）。
  编辑器的编解码、渲染、命中、编辑回填都按宽高独立计算。
- **识图导入**：自动按网格线识别行列，`--width/--height` 可手动覆盖；`month.png`（40×40）识别成功。
- **异形棋盘**：不支持。阴阳的标准规则要求「所有黑格连通、所有白格连通」且棋盘是完整矩形，
  本项目没有「棋盘外空格 / 障碍格」的变体语义，因此异形盘面会改变规则，未实现。
- **验证**：`npm run build`、`npm run check` 通过；内置题参考解/逻辑计划全部合法；
  自定义非正方形（5×6、7×5、9×6、4×4 及 60×4 / 4×60 极限）编解码、渲染比例、命中、求解闭环实测通过。
- **限制**：60×60 级别的题渲染可缩放，但求解/逻辑解题较慢（有节点与时间上限，超时会提示）；
  识图导入的大题默认不带参考解，因此「显示解」不可用。
